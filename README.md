# Karobar Assistant

An AI-powered Business Intelligence & Analytics Platform that helps businesses manage production, sales, inventory, expenses, forecasting, and AI-driven decision-making.

## Vision

Karobar Assistant aims to help businesses make smarter decisions using data analytics, machine learning, and artificial intelligence.

## Status

🚧 Under Development

## Backend

Install dependencies:

```bash
pip install -r backend/requirements.txt
```

Run the API:

```bash
uvicorn backend.main:app --reload
```

## Frontend

Install dependencies:

```bash
cd frontend
npm install
```

Run the app:

```bash
npm run dev
```
